# Platformer Game

A 2D platformer game project featuring a stick man character.

## Features

- Stick man player character
- Platform physics and collision detection
- Smooth movement mechanics
- Multiple levels with increasing difficulty

## Getting Started

### Prerequisites

- Node.js (for serving the game locally)

### Running the Game

1. Clone the repository
2. Serve the game locally using:
   ```bash
   npx serve .
   ```
3. Open your browser to the URL shown (typically http://localhost:3000)
